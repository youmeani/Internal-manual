유미니 구글 계정으로 GitHub 로그인

GitHub 비밀번호 없이, 구글 계정으로 바로 들어갑니다.

  1. 크롬에서 유미니 구글 계정으로 로그인

    크롬 오른쪽 위 프로필에서 youmeani0943@gmail.com으로 로그인되어 있는지 확인합니다. 다른 계정으로 되어 있다면 유미니 계정으로 바꿔 주세요.

  2. github.com 접속 → Sign in 클릭

    주소창에 github.com을 입력해 들어간 뒤, 오른쪽 위 Sign in을 누릅니다.

  3. Continue with Google 클릭

    아이디·비밀번호 칸은 비워 두고, 아래쪽 구글 버튼을 누릅니다.

  4. 계정 선택 화면에서 youmeani0943@gmail.com 선택

    구글 계정 선택 창이 뜨면 유미니 계정을 고릅니다. 잠시 뒤 GitHub 첫 화면(대시보드)이 나오면 로그인 완료입니다.

    구글 버튼으로 들어갔는데 “연결된 계정이 없다”는 안내가 나오면, 첫 칸에 youmeani0943@gmail.com을 입력하고 GitHub 비밀번호로 로그인하세요.
1

저장소(Repository) 만들기

배포할 파일을 담을 폴더를 GitHub에 하나 만듭니다. 작업물 하나당 저장소 하나가 원칙입니다.

  1. 오른쪽 위 + → New repository

  2. Repository name에 저장소 이름 입력

    영문 소문자·숫자·하이픈(-)만 씁니다. 예: event-page, winter-camp-2026. 이 이름이 나중에 웹 주소 끝에 붙습니다.

  3. Public 선택 · Add README 켜기 → Create repository

    무료 계정은 Public(공개) 저장소에서만 Pages 배포가 됩니다. README를 켜 두면 다음 단계 화면이 사진과 똑같이 나옵니다.

2

index.html 올리기

만든 HTML 파일을 끌어다 놓으면 끝입니다.

  1. Add file → Upload files

    방금 만든 저장소 화면에서 파일 목록 위쪽 버튼을 누릅니다.

  2. index.html 파일을 회색 점선 칸에 끌어다 놓기

    이미지 등 다른 파일이 있으면 폴더째 같이 끌어다 놓습니다. HTML 안에 적힌 경로(예: images/main.png)와 폴더 구조가 같아야 그림이 보입니다. 파일 하나당 25MB, 한 번에 100개까지 올릴 수 있습니다.

  3. 맨 아래 Commit changes 클릭

    메모 칸은 비워 둬도 됩니다. Commit directly to the main branch가 선택된 상태 그대로 초록 버튼을 누르면 저장됩니다.

    파일 목록에 index.html이 보이면 올리기 완료입니다. 파일이 폴더 안에 들어가 있지 않고 맨 바깥에 있어야 합니다.
3

GitHub Pages 켜기

“이 저장소를 웹사이트로 공개”하는 스위치를 켭니다. 저장소마다 처음 한 번만 하면 됩니다.

  1. 저장소 위쪽 탭에서 Settings 클릭

  2. 왼쪽 메뉴 Code, planning, and automation 아래 Pages 클릭

    이어서 Build and deployment의 Source가 Deploy from a branch인지 확인합니다. 다른 값이면 이것으로 바꿉니다.

  3. Branch의 None을 눌러 main 선택

  4. 폴더는 / (root) 그대로 두고 Save 클릭

4

배포 주소 확인·공유

Save 후 보통 1~2분, 길면 10분 정도 걸립니다.

  1. Pages 화면 새로고침 → Your site is live at 확인

    위쪽에 주소가 나타나면 배포 완료입니다. Visit site를 눌러 화면을 확인합니다.

  2. 주소를 복사해 공유

    주소 모양은 항상 https://GitHub아이디.github.io/저장소이름/입니다. 휴대폰으로도 한 번 열어 보고 공유하세요.

↻

내용을 고쳐서 다시 올릴 때

Pages 설정은 다시 할 필요 없습니다. 파일만 바꿔 올리면 됩니다.

  1. 같은 저장소에서 Add file → Upload files

    STEP 2와 같은 화면입니다.

  2. 고친 파일을 같은 이름(index.html)으로 올리고 Commit changes

    이름이 같으면 예전 파일이 새 파일로 바뀝니다.

  3. 1~2분 뒤 주소를 열고 Ctrl + F5

    브라우저가 예전 화면을 기억하고 있을 수 있어, 강력 새로고침으로 확인합니다.

자주 막히는 문제

증상해결
주소를 열면 404 화면① 아직 배포 중일 수 있으니 몇 분 기다립니다. ② 파일 이름이 정확히 index.html인지(대문자·띄어쓰기 없이) 확인합니다. ③ 파일이 폴더 안이 아니라 저장소 맨 바깥에 있는지 확인합니다.
글씨는 나오는데 이미지가 안 보임이미지 파일·폴더도 함께 올렸는지 확인합니다. 파일 이름의 대소문자까지 HTML에 적힌 경로와 똑같아야 합니다(Main.png와 main.png는 다른 파일).
고쳤는데 예전 화면이 나옴몇 분 기다린 뒤 Ctrl+F5로 새로고침합니다. 저장소의 Actions 탭에서 pages build and deployment가 초록 체크인지 확인하면 배포 상태를 볼 수 있습니다.
Pages 메뉴에서 Branch를 고를 수 없음저장소가 Private(비공개)일 가능성이 큽니다. Settings → General 맨 아래 Change visibility에서 Public으로 바꿉니다.
Settings 탭이 안 보임창 폭이 좁으면 탭이 접힙니다. 탭 줄 오른쪽 ···를 누르면 Settings가 있습니다.
